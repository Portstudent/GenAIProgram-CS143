# GenAIProgram
Assignment where I use a generative AI model to produce a java program.

## Problem and Prompt

Prompt to Claude :

Create a snake game as a java program that uses OOP design in line with the topics i have learned in my java course so far. The following text is the class's course learning outcomes: 

* 1. Design and implement solutions to ambiguous problems.
* 2. Read and write code using Object Oriented Programming principles, including: classes, Objects, encapsulation, inheritance and interfaces
* 3. Implement, utilize, and compare List implementations (Array and Node)
* 4. Implement, utilize, and compare Collection interfaces and classes, including: abstractions (List, Set, Map, Stack, Queue) and implementations (Hash Table and Tree)
* 5. Read and write recursive methods, including recursive tracing and helper functions
* 6. Process data, including: searching and sorting
* 7. Analyze code in regard to complexity, performance analysis, and dynamic memory management


Do your best not to go outside of the bounds of the course learning outcomes seen here. If this is not possible, tell me. 

The snake game should take place in a rectangle whose ends are solid (meaning the snake cannot hit a wall and come out the other side.) The item that "grows" the snake should be an orange mango. The border of the snake game should be black, the background color off-white / cream, and the snake dark blue. If the snake hits a wall or itself, the snake should disappear piece by piece, from tail to head, until it is completely gone, then a screen should pop up saying "game over." There should be a score count on this screen, which just keeps track of how many fruits have been eaten. There should also be a score count in a corner while playing. Before you generate this code, tell me what you are thinking, if it is possible, and if you have any clarifying questions.

### Reflection

Coding with generative AI was extremely easy and very fast. Claude was able to produce roughly 20 java files in about three minutes that allowed me to have a snake game. The speed and scale of this is a huge benefit that can't be understated. The main drawback is that I really have no clue how this program works. So many random things have been imported and its difficult to trace anything because of how many files there are. I think that although creating this program solo would have taken way longer, it would've allowed for more creative precision on how the snake or fruits looked. This program doesn't feel like mine in any way. I cannot believe Claude had this much precision across so many different files.
